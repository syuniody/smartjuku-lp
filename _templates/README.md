# スマ塾サイト コンテンツ運用ガイド

記事を追加するときの手順と、書き方のルールをまとめています。

## サイト構成

```
smart-juku.syuni.jp/
├── /                サービス紹介（index.html）
├── /case/           制作事例（1塾1ページ）
├── /guide/          塾HPの課題解決記事
├── /report/         一次データ調査
├── /news/           教育ニュース（Edu-NEWSのテキスト版）
├── /assets/site.css 記事・一覧の共通スタイル
├── /_templates/     記事の雛形（公開されません）
└── /scripts/build.py 一覧ページとsitemapの自動生成
```

`/case/index.html` などの**一覧ページと `sitemap.xml` は自動生成**です。直接編集しないでください。

## 記事を1本追加する手順

1. `_templates/article.html` を、置きたいディレクトリにコピーする
   ```bash
   cp _templates/article.html guide/juku-hp-cost.html
   ```
   ファイル名は英小文字とハイフン（`juku-hp-cost.html`）。日本語・アンダースコアは使わない。

2. ファイル内の **★** が付いた箇所をすべて書き換える
   （★が残っていると、そのページは一覧・サイトマップから自動的に除外されます）

3. ビルドする
   ```bash
   python3 scripts/build.py
   ```
   → 一覧ページと `sitemap.xml` が更新されます

4. 公開する
   ```bash
   git add -A && git commit -m "add: 記事タイトル" && git push
   ```
   GitHub Pages が数分で反映します。

5. 反映後、Search Console の「URL検査」でそのURLを入力し、**インデックス登録をリクエスト**すると早く拾われます。

### 公開前の点検

```bash
python3 scripts/build.py --check
```
★の消し忘れ、`description` 未記入、日付欠落などを一覧で教えてくれます。

## 書き方のルール（AI検索に拾われるため）

AI Overviews や ChatGPT検索は「明快に書かれた一次情報」を引用します。以下を守ると引用されやすくなります。

### 1. 見出しは質問形にし、直後に結論を置く

```html
<h2>塾のホームページ制作にいくらかかる？</h2>
<div class="answer">
  <p>自作なら0円〜、制作会社に頼むと30〜100万円が相場です。</p>
</div>
```
`.answer` は青枠＋「結論」バッジで表示されます。**必ず数値や断定を含める**こと。

### 2. 数値は表にする

`.data-table` を使う。`<caption>` に表タイトル、金額のセルには `class="num"` を付けると右寄せ＋等幅になります。表の下には `.table-note` で調査日や対象数を書く。

### 3. 調査記事には「調査概要」を必ず置く

`.survey-meta`（テンプレートにコメントアウトで用意済み）に、**調査対象・期間・方法・主体**を明記します。これが無いとAIも読者も数値を信用しません。

### 4. 引用を歓迎する旨を書く

`.citation` ブロック。出典表記の例をそのまま置いておくと、メディアやAIがそのURLを引用元として使ってくれます。

### 5. FAQを載せる場合

テンプレート内の `FAQPage` のJSON-LDをコメント解除して使います。
**本文のQ&Aと、JSON-LD内の文言を一字一句同じにする**こと（不一致はGoogleのガイドライン違反）。

## 品質の方針

- **月2〜4本**。薄い記事の量産は逆効果です
- **実データか実体験があるものだけ**書く
- noteとは書き分ける：本文（ノウハウ・調査）は自社サイト、noteは現場の話や失敗談など「書き手を読みに来る層」向け。要約だけ載せて誘導する形は採らない

## 優先度の高いコンテンツ

1. **`/report/` 一次データ調査** — 診断バッチで集めた塾HPのデータを集計（スマホ対応率・料金掲載率・更新停止率など）。手元にデータがあるぶん最短で形になり、営業資料にもなる
2. **`/case/` 制作事例** — 掲載した塾から「制作：スマ塾」でリンクをもらえるため、自然な被リンクにつながる
3. **`/guide/`** — 「塾 ホームページ 制作 費用」「学習塾 HP 自作」など、実際に検索される語に1テーマ1ページで対応

## セクションを増やしたいとき

`scripts/build.py` の冒頭 `SECTIONS` に1件追加して `python3 scripts/build.py` を実行すれば、ディレクトリと一覧ページが自動で作られます。
