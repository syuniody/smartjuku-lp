# DESIGN.md — Edu-biz通信

**適用範囲：`demo/edubiz-tsushin/` 配下のみ。**

このディレクトリは**すららネットの媒体**であり、スマ塾のページではない。
リポジトリ直下の `DESIGN.md`（スマ塾の規約）は**適用しない**。赤ペン・蛍光ペン・
Shippori Mincho × Zen Kaku Gothic New・角丸トークンなど、スマ塾側の値を持ち込まないこと。
逆に、ここで決めた値をスマ塾側へ持ち出さないこと。

同居しているのは限定公開のプレビュー置き場としてであり、
本番はいずれ**すららネット管理のドメインへ移す**。

## この媒体は何か

学習塾向けYouTube「Edu-bizチャンネル」（すららネット運営）の、
**導入塾さま向け隔週ダイジェスト**。2週間で公開した6本前後から3本を選び、
ブログ風のダイジェストを書いて動画を埋め込む。読者は塾の経営者・教室長。

**目的はチャンネルの視聴を増やすこと。**動画はページ内で再生できる形にする
（埋め込み再生も再生回数・視聴時間に加算されるため）。

## Signature — 記憶に残す一点

**「通信」の題字部（だいじぶ）。**
h1 の直下に、太い罫（3px ネイビー）と細い罫（1px）で挟んだデータ欄を置き、
**収録／選定／編集**の3項目を必ず載せる。

```
収録  2026年8月11日〜24日に公開した6本
選定  秋の保護者面談で説明を求められる可能性が高い順
編集  小田 一勲（Edu-bizチャンネル MC）
```

なぜこれか：この媒体の価値は装飾ではなく**編集者の判断**にある。
「誰が・いつ・何を基準に6本から3本を選んだか」が読者にとっての信頼の根拠であり、
毎号戻ってくる理由でもある。学級通信・塾だよりの紙面に実在する形式でもあるため、
この業界の読者には説明なしで通じる。

**大胆さはここだけ。**他は静かに保つ。

**「選定」は毎号書き直すこと。**前号のコピーを使い回した時点で、この欄は死ぬ。

## 主従は「サイズ」ではなく「言葉」で付ける

**3本のサイズは揃える。**（記事ページ：埋め込み 520px・見出し clamp(20px, 4.5vw, 26px)／
メール：サムネイル 420px・見出し 18px）

一度、1本目だけ大きくして主役に立てたことがある（2026-08-24）。
「編集者の判断が見えない」というレビューへの対応だったが、**読者には
「重要だから大きい」ではなく、ただの不揃いにしか見えなかった。**

> 「ピックアップ」とか「これは必見」とか書いてあったら分かるけど、
> 単純に不揃いに見えた（小田さん）

**サイズ差は、それ単体では意味を運ばない。**主従を出したいなら、
ラベルや一言で明示すること。書かないなら揃えること。中途半端が一番悪い。

なお、同じ構成のブロックを3つ積むこと自体はテンプレートに見えやすい。
サイズ以外（ラベルの文言・文章量・並び順の根拠）で差を作る。

順番は再生数順ではなく、**塾の現場に効く順**で決める。
その基準を題字部の「選定」に書く（これは維持）。

## 動画の扱い

- ピックアップ3本は **YouTube埋め込み**（`youtube-nocookie.com`、`loading="lazy"`）
- 「今号のその他の動画」は**埋め込まない**。サムネイルのリンクに留める
  （iframe を6個置くと重い）
- **埋め込みの直下にボタンを置かない。**その場で再生できるので冗長で、
  濃紺のボタンが3つ並ぶとテンプレートのリズムを強める。
  代わりに**静かなキャプション1行**（`公開日｜尺　YouTubeで開く`）を置く
- サムネイルは黄色・赤の大きな文字で作られているため、**大きくすると誌面がチカチカする**。
  一覧カードは 185px 幅（グリッド幅 600px 上限）を上限とする

## 禁止

- **同じ形のカードを意味なく3枚横並びにする**（一覧は幅を絞って従属させる）
- **「大きな数字＋小さなラベル」を等分割で並べる統計バー。**
  2026-08-24 に「更新：毎週3本／登録者：7,840人／対象：塾経営者・教室長」を撤去した。
  生成AIが最も出しやすい形であり、本文で既に述べた事実の再掲でもある
- 中央寄せの見出し＋中央寄せの説明＋中央寄せのボタン、という**汎用LPのCTAバンド**。
  CTAは本文カラム幅に収め、左に文言・右にボタンで組む
- 意味のないアイコン・グラデーション・ピル型ラベル・ガラス風の半透明
- 題字部と本文で同じ情報を二度書く
  （2026-08-24 にリード文末の「6本のうち3本を掘り下げます」を削除。題字部の「収録」と重複）
- Lorem ipsum・英語ダミー。**必ず本番の日本語で設計する**

## HTMLメール（`vol01/email.html`）

記事ページと**同じ題字部・同じ階層・同じ色**で組む。別デザインにしない。

### 組み方

- **テーブルレイアウト＋インラインstyleのみ。**flex / grid / `border-radius` を使わない
  （Outlookが解釈しない）。`<table role="presentation">` に `cellpadding=0 cellspacing=0 border=0`
- 本文幅 **600px**。外側は `#E9E7E1`、本体は `#FFFFFF`
- **画像は絶対URLで参照する。**相対パスはメールでは解決しない
- `<img>` に `width` / `height` / `alt` / `display:block` を必ず付ける。
  **画像がブロックされても意味が通るaltを書く**
- Retina対応：表示幅の2倍の実寸画像を置き、`width` 属性で縮める
- `<head>` の `<style>` はメディアクエリと打ち消しだけに使う。
  **レイアウトを `<style>` に依存させない**（配信ツールに削られることがある）
- **プリヘッダー**（受信箱で件名の後ろに出る一文）を必ず入れる
- 配信停止リンクと発行元表記は必須。停止URLは配信ツールの差し込みタグに置き換える
  （現在は `%%unsubscribe_url%%` のプレースホルダ）

### 記事ページとの違い（意図的なもの）

- 動画は**埋め込まない**。サムネイル画像をYouTubeへのリンクにする（メールでは再生できない）
- 丸写真は**あらかじめ丸くマスクして白背景を焼き込んだPNG**を使う。
  `border-radius` はOutlookで効かず四角になる
- サムネイルは**3本とも 420px**、見出しは**3本とも 18px**で揃える。
  **本文幅いっぱい（536px）にしない。**メールは横幅が狭く、いっぱいに広げると
  サムネイルの派手さで文字が読まれなくなる
- あいさつの丸写真は、顔の寄りではなく**胸から上**が入る範囲で切り抜く。
  80pxの円に顔だけを詰めると窮屈で、証明写真のように見える

### 禁止

- **ヘッダー全体を1枚画像にしない。**画像ブロック時にヘッダーが真っ白になる。
  題字と号数は必ず文字で残す
- Webフォントを当てにしない（メールクライアントは読み込まない前提で組む）
- 背景画像・position指定・JavaScript

## 確認

**ビルドが通っただけでは完成としない。**
本番の日本語で `1440px / 390px` を目視する。

スクリーンショットが撮れないときは DOM実測（色数・角丸・影・段落間・要素幅・
`scrollWidth`）で代替し、**「画面を見ずに数値で判断した」と明記する**。見たふりをしない。

YouTube埋め込みがあるページは、ブラウザのプレビューで**スクロール後の描画が
真っ白になることがある**。ビューポートを縦に大きくして一度に撮ると回避できる。
